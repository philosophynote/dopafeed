# ADR 0015: 登録前にフィードを検証し、記事の取り込みは Job に任せる
日付: 2026-11-07 状態: 採用（#77 の計画を nao が承認）

- RSS/Atom を HttpGet で取得し、FeedDocument の strict な XML 解析とタイトル確認に成功してから Feed を作る。FeedFetcher と解析を共用し、記事は既存の FetchFeedJob で取り込む。
- 未コミットの Feed をワーカーが見つけられず捨てる競合を避けるため、保存が確定してから予約する。予約失敗時も登録を残し、後ほど再試行する旨を伝えて定期取得に任せる。取得・解析の失敗では登録しない。
- URL の前後の空白・フラグメントを除き、登録済みなら取得も予約もしない。同時登録は DB の一意制約でも防ぐ。
- シートに登録結果を表示し、閉じると Main / Feeds の開いた側を再読み込みする。取り込み前の記事数は表示しない。戻り先はこの二択に限る。
- サイト URL の自動検出は #81。標準の貼り付けを使い、クリップボード読取ボタンは置かない。おすすめは画面仕様の固定文。
