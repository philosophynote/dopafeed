# ADR 0032: 読むモードでも左へ払えば削除する
日付: 2026-11-22 状態: 採用（#171）。ADR 0023 の「Main の行の左スワイプは削除しない」と、ADR 0030 の「読むモードの左は今までどおり動かない」「引いている間に『読む』へ戻されたら、左へ引いた分は削除にしない」を改める。記録（ADR 0012 の `articles.dismissed_at`）は変えない

nao の依頼（2026-11-22「通常モードでも削除できるようにしたい」）。#171 の計画で 3 案（A 左払いで削除 / B 読むモードだけ深く引く / C 広げた欄に削除ボタン）を示し、nao が決定札で A を選んだ。

- **読むモードでも、行を左へ払うと削除。** 判定（`swipe.dismiss_threshold_ratio` と `swipe.flick_*`）、背景、送信の列、トーストは処理モードと同じ。左 = 削除・右 = 保存がモードを問わず揃う
- **処理モードは残す。** 続けて片付ける場として、コンボ・メロディ・節目・リザルトはそのまま
- **読むモードの削除はコンボ・リザルト・節目に数えない。** 数えるかは離した時点のモードで決める。処理モードで左へ引いたまま「読む」に戻して離すと、削除はするが数えない。カード・今日のゴール・ストリークも動かさない（ADR 0012）
- **音は右スワイプと同じ。** 読むモードでは閾値を越えた瞬間に `swipe` を 1 回鳴らす。処理モードは今どおりメロディだけ
- **B を採らない理由:** 読むモードだけ閾値を深くすると、モードで指の覚えが変わり、`swipe.*` に新しい鍵が要る
- **C を採らない理由:** 1 本ごとにタップ → 押すの 2 手で、払って片付ける速さが出ない
- **失うもの:** 読むつもりで横にずれた指で消える恐れ（ADR 0023 がやめた理由）。閾値まで引かねば消えず、消えてもトーストの「元に戻す」で戻せる。キーボードと VoiceOver からは削除できない。要るなら C のボタンを後で足す
