# ADR 0014: 購読の削除は記事と読了も削除する
日付: 2026-11-07 状態: 採用（#72 の計画を nao が承認）

- 購読停止の列は追加せず、既存の `Feed → Article → Reading` の `dependent: :destroy` を使う。記事のいいね・保存も消える。
- 読了由来の累計 XP・読了数・連続日数は残った Reading から再計算される。削除確認にこの影響を明示する。
- 達成済み DailyGoal とそのボーナスは残す。再登録で記事を取り直せば XP を再び得られる。一人用の購読管理として許容する。
- 履歴を残す購読停止は、取得対象・未読・保存・報酬集計をまたぐ変更になるため採らない。
