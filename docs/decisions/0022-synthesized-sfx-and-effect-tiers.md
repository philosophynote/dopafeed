# ADR 0022: 効果音はその場で合成し、演出は一度に一番大きい 1 つだけを出す
日付: 2026-11-12 状態: 採用（#100）。SPEC の「振動不可 → 効果音と CSS アニメーション」の効果音の作り方を決める。#45 を閉じる

nao の決定（2026-11-08「ドーパミン成分が足りない、dopairb を参照して」→ #106 で XP を図鑑に置き換えた後に計画を書き直し、2026-11-12 推奨どおり承認）。

## 決めたこと
- **音は Web Audio で合成する。** オシレータとノイズだけで作り、音源ファイルを置かない（dopairb と同じ）。ライセンスの確認も読み込み待ちも要らない。mp3 を置く案は採らない
- **iPhone の消音スイッチに従う。** `navigator.audioSession.type = "ambient"` を明示する。消音スイッチが ON なら鳴らず、聴いている音楽やポッドキャストも止めない。消音を越えて鳴る `"playback"` は使わない（通勤中に突然鳴るアプリは消される）
- **AudioContext は最初の操作で起こす。** iOS は利用者の操作の中でしか音を出させない。指の pointerdown は操作に数えられないので、pointerup・touchend・click・keydown で作って起こし、無音を一度流す。それより前の音は捨てる。バックグラウンドや着信で止められた（"interrupted"）ら、次の操作で起こし直す
- **切り替えは設定画面の「効果音」トグル。** 端末ごと（localStorage）。初期値は鳴る。サーバーには送らない（鳴らすかは、その端末をどこで使うかで決まる）
- **鳴らすのは現れた瞬間の 1 回だけ。** 判定の区切りと Main の帯は、判定・抽選した応答でだけ鳴らし、再読込・履歴で戻った画面・bfcache では鳴り直さない（めくりと同じ考え）。画面そのものが演出の Jackpot と宝箱は開くたびに鳴る（宝箱は 22c で、その日最初の 1 回だけのフィナーレに改める）
- **動きに合わせて鳴らす。** ルーレットは止まった瞬間に鳴らし、`prefers-reduced-motion` で CSS がすぐ止めるときは待たずに鳴らす。応答を待つ間に別の行を広げられて隠れたまま届いた欄では鳴らさない
- **通常の出目は鳴らさない。** レアはチャイム、金は和音。毎回鳴ると上の段が出たときに効かなくなる（帯が光るのを通常以外に限ったのと同じ）
- **演出は小・中・大・特大の段に分け、同時に起きたら一番大きい 1 つだけを出す。** 残りは副題に 1 行で畳み、キューに積まない。押せば即終わり、結果の文字とカードは残る。失敗（カードにならなかった）は柔らかい煙の音で、笑わない。段と判定は 22b で `CardHighlights` が決める（サーバーが決め、クライアントは見せるだけ）
- **test 環境では鳴らさない。** `config.x.sfx_record` のとき、鳴らした音の名前を sessionStorage に記録し、system spec が読む

## 鳴らす場所（22a）
| 場面 | 音 |
|---|---|
| 行のタップ（Main・Saved） | tap |
| スワイプが閾値を越えた瞬間 | swipe |
| Main で行を広げた（帯） | レアは rare、金は gold（通常は無音） |
| Saved のルーレットが止まった | レアは rare（通常は無音。金は直後の Jackpot のファンファーレに譲る） |
| Reader に継ぎ足した次の記事の帯 | 鳴らさない（同じ瞬間に区切りの音が鳴る） |
| Jackpot の予告 | fanfare |
| 判定の区切り | 完読は card（めくり）、未完は puff。金の全画面の開封が出るときは fanfare だけ |
| 宝箱（達成後の DailyGoal） | chest |
| 設定で効果音をオンに戻した | tap（試しに） |

## 見せ場の段（22b）
`CardHighlights`（app/models）が、判定した Reading と過去の行から起きたことを段の大きい順に並べる。数字は既存の鍵と `cards.fever_combo`（nao が 5 で採用）からだけ導く。
| 段 | 見せ場 | 音 |
|---|---|---|
| 特大 | NEW RECORD（今日の連続が過去の最長を初めて超えた。過去の最長が 2 以上のときだけ）、金のカード | fanfare |
| 大 | COMEBACK、取り返した、NEW FEED、FIRST CARD | highlight |
| 中 | FEVER（`cards.fever_combo` 以上）、n 連続（2 以上） | combo（連続で音程が上がる） |
| 小 | なし | card |
- NEW RECORD は、今の連続に入っている行を比べ相手から外して判定する。外さないと、記録を超えた後の 1 枚ごとに出てしまう
- 見せ場は判定した直後の応答でだけ描き、描き直しでは計算しない（毎回数え直すと、再読込のたびに「起きた」ことになる）
