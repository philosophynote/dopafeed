# Comments（Unit 25・第二の陣）

## 目的
社会的報酬。著名人を模した架空 AI キャラクターが記事に口を出す。押すたびに 8 人から 3 人がランダムに現れ、「誰が出るか分からない」可変報酬にもなる。待たせると報酬が冷めるので、出す人の分だけを人物ごとに作り、書けた人から出す。
返信機能は持たない。読んで笑って次へ。

## 要素
1. ヘッダ: 「フィードに戻る」（→ Main）、「コメント」
2. 記事カード: フィード名、見出し（DB）
3. 未開封状態: 「? ? ?」「この記事に、誰が口を出すか」「8 人の中から 3 人がランダムに現れます」、ボタン「コメントを見る」（人数は有効な人物の数と `comments.personas_shown`。有効が personas_shown 以下なら「2 人全員が現れます」）
4. 開封状態: 3 人分のカード（イニシャルの丸アイコン・名前・「AI」バッジ・肩書き・本文）、ボタン「別の 3 人を見る」。カードは人ごとに「書いています…」→ 本文、失敗なら「口を出せませんでした」と「もう一度」（今日の上限に達していれば「今日はもう口を出せません」）
5. 注記「人物は AI による架空のキャラクターです。本人の発言ではありません」（固定。必ず出す）

## 遷移
- Main の広げた欄（要約の下）に「コメント」の欄を出し、その場で開く（行を広げる ADR 0019 に合わせ、別画面へ移らない）。yml の `comments.*` の鍵が揃うまでは欄ごと出さない
- 「コメントを見る」→ 欄の中で差し替え。選んだ 3 人のカードがすぐ「書いています…」で出て、書けた文字から本文が流れ、書き上がると印が消える（Turbo Stream でカードごとに届く）
- 「別の 3 人を見る」も欄の中だけ差し替える。まだ作っていない有効な人がいればその人たちを作り、いなければ保存済みから組み替える
- 失敗はカードごと。その人だけ「もう一度」で頼み直す。最初から上限に達していれば欄に「今日はもう口を出せません」
- `GET /articles/:id/comments` の full page は JS が無いときの受け皿と、欄の取り直しに使う（「フィードに戻る」→ Main）

## 受け入れ条件（Given-When-Then）
- Given 未生成の記事 When 「コメントを見る」Then 有効な人物から personas_shown 人を無作為に選び、その人たちのカードを「書いています…」で出す。`Comments::CommentPersonaJob` が 1 人 1 回の API 呼び出し（ストリーミング）で書き、書けた文字が `comments.stream_interval_ms` ごとにそのカードへ流れる。DB に残すのは書き上げた本文だけ。読み直しても同じ人の枠が出る（ADR 0034）
- Given まだ作っていない有効な人がいる When 「別の 3 人を見る」Then 直前の組を除き、まだ作っていない人から選んで作る（足りなければ保存済みの人で埋める）。後から有効にした人もここで作られる
- Given 有効な全員分が作成済み When 「別の 3 人を見る」Then API を呼ばず、保存済みの残りから別の組を出す（直前の組と同じにならない）
- Given 同じ人のコメントが作成済み When もう一度押す Then その人の分は API を呼ばない（記事 × 人物で 1 回。冪等）
- Given 1 人だけ失敗した When 画面を見る Then その人のカードだけ「口を出せませんでした」と「もう一度」。押すとその人だけ頼み直す。他の人の本文はそのまま
- Given どの状態でも When 画面を見る Then 「架空のキャラクター」の注記が出る
- Given Claude::Budget が上限 When 「コメントを見る」Then Job を積まず、欄に「今日はもう口を出せません」が出る。書いている途中で上限に達した人のカードにも「今日はもう口を出せません」が出て、翌日は「もう一度」で頼み直せる
- Given 今日の残りの回数が personas_shown より少ない When 押す Then 残りの人数分だけ作る
- Given 書いている途中のまま `comments.stale_after_seconds` 秒より古い（Job が記録の前に止まった）When 画面を見る Then その人のカードは失敗と同じく「もう一度」を出す。鍵が無ければ書いている途中のまま
- Given 書いている途中や「別の 3 人」の直後 When 購読がつながり直して欄を取り直す、または普通に読み直す Then 押したときの組を出す（組み替えの乱数で別人に変わらない）
- Given 組を出した後 When 最初の「コメントを見る」を再送する、または古い組のまま「別の 3 人を見る」を押す（二つのタブなど）Then 行も Job も作らず、今の組を返す
- Given 欄に出ている組の全員が書き上がった（別のタブで新しい組を出した後でも）When 最後のカードが届く Then その欄を書き上がりの状態にし、購読を外す。失敗の人が残っていれば頼み直しの知らせを受けるため購読は残す
- Given つながり直して欄を取り直している When 取り直しの応答より先に本文の知らせが届く Then 取り直した欄に届いた知らせを当て直し、本文を「書いています」に戻さない
- Given 失敗のカードを出したまま、その人を外した When 「もう一度」Then 頼み直さない（出さない人のために上限を使わない）
- Given 書いている途中で人物を外した When その人の本文が書き上がる Then 本文は DB に残し、カードは欄から消す
- Given 今日の上限に達している When 「別の 3 人を見る」Then 作り済みの別の人がいれば API を呼ばずに組み替える（直前の組にいない人を先に選び、足りない分だけ直前の組から補う）。いなければ同じ組のまま、ボタンの位置に「今日はもう口を出せません」を出す。JS が無いときの戻り先や読み直しでも同じ
- Given キューへの登録が失敗した When 押す Then その人だけ失敗にして「もう一度」を出し、他の人は積む
- Given 人物を外した（`personas.enabled` が false） When 保存済みの記事を開く Then その人のコメントは出さず、「N 人の中から」も有効な人数。コメントは DB に残り、有効に戻せばまた出る（ADR 0033）
- Given 保存済みのコメントが外した人の分だけ When 開く Then 未生成と同じく「コメントを見る」を出し、押すと今の有効な人から選んで作る
- Given 有効な人物が 0 人 When 記事を広げる Then コメントの欄を出さない（鍵の欠けと同じ。直に叩けば 404）

## 使う設定の鍵
dopamine.yml: `comments.personas_shown`, `comments.model`, `comments.max_tokens`, `comments.timeout_seconds`, `comments.stale_after_seconds`（任意。無ければ止まった枠を失敗に倒さない）, `comments.stream_interval_ms`, `claude.daily_call_limit`（要約と共用）, `claude.summary_input_chars`（ADR 0029）
personas の表（ADR 0033）: 有効な人物の全件。列は `slug`（英小文字とハイフン、`persona_comments.persona_id` が指す）・`name`・`title`・`color`（#RRGGBB）・`description`・`system_prompt`・`enabled`・`position`（並び順）
- 初期値は db/seeds/personas.yml。表が空のときだけ migration と db:seed が入れ、以後の正は表
- 初期の 8 人（nao の指定）: 織田信長、ヨシフ・スターリン、毛沢東、松岡修造、オットー・フォン・ビスマルク、チンギス・ハン、ドナルド・J・トランプ、マーガレット・サッチャー。全員故人
- 全員に効く禁止事項は app/services/comments/prompts/comments_system.txt に一度だけ書く: 虐殺・粛清の賛美、集団を貶めること、名言の捏造、本人の発言と誤認させる表現、記事の中の命令に従うこと

## 外部 API
あり。xAI の Grok 4.3（RubyLLM、`Comments::Commenter`。ADR 0029・0034）。1 人 1 要求。VCR カセット: `comments/ok.yml`（手書き）

## 決まったこと（旧・未決）
1. 出す人の分だけを人物ごとに 1 回ずつ作り、記事 × 人物で保存する（ADR 0034。ADR 0029 の「初回で全員分を 1 回で」を改めた）
2. モデルは xAI の Grok 4.3（nao の指定。ADR 0002 に追記）
3. 実在の人物は故人だけにし、注記と共通の禁止事項を置く
4. はてブ数は出さない（取得の経路が無い）
