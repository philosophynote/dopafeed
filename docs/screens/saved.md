# Saved（Unit 未定・第二の陣。案: 17）

## 目的
いいねかブックマークした記事の置き場。「あとで読む」ではなく「読み返す」ため。保存記事との類似（Similar）の起点にもなる。

## 要素
1. 「保存 (5)」（DB: 保存数）
2. 「保存した記事に似ている未読 3 件」カード（→ Similar。見出し、「84%」、理由）
3. 保存記事の一覧（新しい順）: 見出し、フィード名 ・ 相対時刻、「似た未読 1」バッジ。タップで元記事（外部 URL）
4. 注記「フィードでハートかブックマークを押した記事がここに溜まります。タップすると記事を開きます」（固定）
5. タブバー（保存が選択）

## 遷移
- タブバー「保存」→ Saved（full page）
- Saved → 外部 URL（PWA 内のブラウザシート）/ Similar

## 受け入れ条件（Given-When-Then）
- Given いいね 3 本・ブックマーク 2 本（重複 0）When Saved を開く Then 「保存 (5)」で 5 本が保存日時の新しい順
- Given いいねもブックマークも 0 When Saved を開く Then 空状態の文言
- Given 保存を解除 When 一覧 Then Turbo Stream でその行が消える
