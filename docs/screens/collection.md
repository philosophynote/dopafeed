# Collection（図鑑。Unit 23b、#106、ADR 0020）

## 目的
「手に入れて残るもの」の置き場。完読した記事 1 本がカード 1 枚になり、ここに溜まる。数字の XP に代わる積み上がりの感覚を担う（可変報酬の結果が残る場所。報酬距離の「次の 1 枚」もここで見える）。モックには無い画面で、タブ「レポート」の枠に置く（Weekly は後で図鑑の中の集計に畳む）。

## 要素
1. 見出し「図鑑」と枚数「N 枚」（DB: `Reading.card_count`）。その下に内訳「通常 a ・ レア b ・ 金 c」（DB: `Reading.completed.group(:tier).count`。段と順は `cards.rarities`、名前は locale `dopamine.rarities`）と「🔥 N 日連続」（DB: `ReadingStreak.days`）
2. 完読日ごとの束（新しい日が上。日付は `ReadingDay`、reset_hour で切る）: 見出し「今日」「昨日」、それより前は「11月6日（木）」。束の中はカードのグリッド 3 列、同じ日の中は完読の新しい順
3. カード 1 枚（`cards/_card`。23c の開封と宝箱で同じ部品を使う）: 縦長（3:4）。表は OGP 画像（DB: `articles.image_url`。無ければ、読めなければフィードごとの色地）に見出し（最大 3 行）とフィード名を重ねる。枠の色が希少度（通常 = 灰、レア = 橙、金 = 金。`rarity_frame`）。左上に希少度のラベル（通常は出さない。レア・金だけ）。`data-tier` を持つ
4. 空状態（0 枚）: 「まだカードはありません。」「記事を S 秒以上読むと、その記事がカードになってここに残ります。」（S = `read.complete_after_seconds`）
5. タブバー（図鑑が選択。「レポート」の無効な枠はこれに替わる）

出さないもの: 滞在時間・完読時刻・コンボ（カードの裏に当たる情報は 23c 以降）。レベル・称号（持ち越し）。

## 遷移
- タブバー「図鑑」→ Collection（full page、`GET /collection`）
- カードをタップ → 元記事を別窓（iPhone のホーム画面アプリではシート）で開く。読み直しても抽選し直さず、カードも増えない（`Reading` は 1 記事 1 行）
- Main のステータス行の「N 枚」は行ごと DailyGoal へのリンクのままで、図鑑への入口はタブだけ（1 行に 2 つのリンクを置かない）

## 受け入れ条件（Given-When-Then）
- Given カードが 0 枚 When 図鑑を開く Then 「図鑑」「0 枚」と空状態の文言（S は yml）、束は無い
- Given 今日 2 枚・昨日 1 枚・3 日前 1 枚 When 図鑑を開く Then 束は「今日」「昨日」「M月D日（曜）」の順で、今日の束に 2 枚が完読の新しい順
- Given reset_hour の手前（午前 3 時）に完読したカード When 図鑑を開く Then 前日の束に入る
- Given 通常 3・レア 1・金 1 When 図鑑を開く Then 「5 枚」「通常 3 ・ レア 1 ・ 金 1」。金のカードは金の枠と「金」のラベル、レアは橙の枠と「レア」のラベル、通常にはラベルが無い
- Given 未完の行（開いただけ）と未読の記事 When 図鑑を開く Then カードに出ない
- Given OGP 画像のある記事のカード When 見る Then 画像が表に出る。無い記事はフィードの色地に見出し
- Given カード When タップ Then 元記事が別窓（`target=_blank`、noopener）で開く
- Given 図鑑 When タブバーを見る Then 「図鑑」が現在地で、「レポート」は無い。他の画面でも「図鑑」のタブは有効
- Given 390×844 で 30 枚 When 図鑑を開く Then 横スクロールが無く、カードのタップ領域は 44px 以上、3 列に並ぶ

## 使う設定の鍵
dopamine.yml: `cards.rarities`（内訳の段と順、枠の色）、`read.complete_after_seconds`（空状態の文言）、`daily_goal.reset_hour`（束の日付）
personas.yml: なし
