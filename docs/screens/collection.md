# Collection（図鑑。Unit 23b、#106、ADR 0020）とカードの裏（#134）

## 目的
「手に入れて残るもの」の置き場。完読した記事 1 本がカード 1 枚になり、ここに溜まる。数字の XP に代わる積み上がりの感覚を担う（可変報酬の結果が残る場所。報酬距離の「次の 1 枚」もここで見える）。モックには無い画面で、タブ「レポート」の枠に置く（Weekly は後で図鑑の中の集計に畳む）。

## 要素
1. 見出し「図鑑」と枚数「N 枚」（DB: `Reading.completed` の数。Main の `Reading.card_count` と同じ数え方）。その下に内訳「ノーマル a ・ レア b ・ S レア c ・ SS レア d」（判定中のカードがあるときだけ「・ 判定中 e」を足す。DB: 完読の行を tier で数える。段と順は `cards.rarities`、名前は locale `dopamine.rarities`）と「🔥 N 日連続」（DB: `ReadingStreak.days`。読み上げは「読んだ日が N 日連続」）
2. 完読日ごとの束（新しい日が上。日付は `ReadingDay`、reset_hour で切る）: 見出し「今日」「昨日」、それより前は「11月6日（木）」。束の中はカードのグリッド 3 列、同じ日の中は完読の新しい順
3. カード 1 枚（`cards/_card`。区切りの開封と宝箱でも同じ部品を使い、そちらは `reveal` で裏からめくる。図鑑ではめくらない）: 縦長（3:4）。表は OGP 画像（DB: `articles.image_url`。無ければ、読めなければフィードごとの色地）に見出し（最大 3 行）とフィード名を重ねる。枠の色が希少度（ノーマル = 灰、レア = 橙、S レア = 紫、SS レア = 金、判定中 = 灰の破線。`rarity_frame`）。左上に希少度のラベル（ノーマルは出さない。判定中は「判定中」）。`data-tier` を持つ
4. 空状態（0 枚）: 「まだカードはありません。」「記事を S 秒以上読むと、その記事がカードになってここに残ります。」（S = `read.complete_after_seconds`）
5. タブバー（図鑑が選択。「レポート」の無効な枠はこれに替わる）

出さないもの: 滞在時間・完読時刻・コンボ。レベル・称号（持ち越し）。

### カードの裏（`GET /cards/:id`。#134）
図鑑のカードを押すと開く。そのカードの枠がなぜその段なのか（記事の中身の 6 軸の点）を見せる。
1. 「‹ 図鑑へ戻る」（図鑑の、見ていたカードの位置へ戻る）
2. カード（`cards/_card`。押せない面だけ）、枠の根拠と段「24 点 ・ レアカード」（判定の無いまま一番下の段に決まったカードは「判定できず ・ ノーマルカード」、枠と判定の段が食い違うカードは段だけ、判定中は「判定中」）、見出し、フィード名と読了の日（「今日」「昨日」「11月6日（木）」に読了）
3. 6 軸のレーダー（`judgments/_radar`。サーバーが描く SVG。独自性を真上に時計回りで 深掘り・実践性・根拠・洞察・応用性。軸ごとに名前と 1〜5 の点、下に「合計 24 点」。DB: `article_judgments`）。枠と判定の段が食い違うカード（枠が決まった後に判定が届いた、境界を変えた）は「合計 24 点 ・ 付け直すとレア」（`judgments:regrade[apply]` を打つとその段になる）。判定できなかった記事は図の代わりに「この記事は判定できなかったので、点はありません。」、判定中は「判定が届くと、6 軸の点がここに出ます。」
4. 「記事を開く」（元記事を別窓。iPhone のホーム画面アプリではシート）
5. タブバー（「図鑑」が現在地）

## 遷移
- タブバー「図鑑」→ Collection（full page、`GET /collection`）
- カードをタップ → カードの裏（full page、`GET /cards/:id`）。「図鑑へ戻る」で Collection へ
- カードの裏の「記事を開く」→ 元記事を別窓（iPhone のホーム画面アプリではシート）で開く。読み直しても枠は変わらず、カードも増えない（`Reading` は 1 記事 1 行）
- Main のステータス行の「N 枚」は行ごと DailyGoal へのリンクのままで、図鑑への入口はタブだけ（1 行に 2 つのリンクを置かない）

## 受け入れ条件（Given-When-Then）
- Given カードが 0 枚 When 図鑑を開く Then 「図鑑」「0 枚」と空状態の文言（S は yml）、束は無い
- Given 今日 2 枚・昨日 1 枚・3 日前 1 枚 When 図鑑を開く Then 束は「今日」「昨日」「M月D日（曜）」の順で、今日の束に 2 枚が完読の新しい順
- Given reset_hour の手前（午前 3 時）に完読したカード When 図鑑を開く Then 前日の束に入る
- Given ノーマル 3・レア 1・SS レア 1 When 図鑑を開く Then 「5 枚」「ノーマル 3 ・ レア 1 ・ S レア 0 ・ SS レア 1」。SS レアのカードは金の枠と「SS レア」のラベル、レアは橙の枠と「レア」のラベル、ノーマルにはラベルが無い
- Given S レアと判定中のカード When 図鑑を開く Then S レアは紫の枠、判定中は破線の枠と「判定中」のラベルで、内訳に「判定中 1」が足される（#134）
- Given 未完の行（開いただけ）と未読の記事 When 図鑑を開く Then カードに出ない
- Given OGP 画像のある記事のカード When 見る Then 画像が表に出る。無い記事はフィードの色地に見出し
- Given カード When タップ Then カードの裏が開く（#134。元記事は裏の「記事を開く」から別窓で開く。`target=_blank`、noopener）
- Given 判定済みのカード When 裏を開く Then カード、「24 点 ・ レアカード」、見出し、6 軸のレーダー（軸ごとの名前と点）、「合計 24 点」、「記事を開く」が出る。読み上げには 6 軸の点がまとめて渡る（#134）
- Given 判定できなかった記事のカード When 裏を開く Then 図は出ず「判定できず ・ ノーマルカード」と理由が出る。判定中のカードは「判定中」と、届くと出る旨（#134）
- Given 枠と判定の段が食い違うカード When 裏を開く Then 「判定できず」とは出さず、図の下に「付け直すと<段>」が添えられる（#134）
- Given 図鑑を下へ送って押したカードの裏 When 「図鑑へ戻る」を押す Then 図鑑のそのカードの位置に戻る。タブバーは裏でも「図鑑」が現在地（#134）
- Given 完読していない行の id When `/cards/:id` を開く Then 404（#134）
- Given 390×844 When カードの裏を開く Then 横スクロールが無く、軸の名前は図からはみ出さず、タップ領域は 44px 以上（#134）
- Given 図鑑 When タブバーを見る Then 「図鑑」が現在地で、「レポート」は無い。他の画面でも「図鑑」のタブは有効
- Given 390×844 で 30 枚 When 図鑑を開く Then 横スクロールが無く、カードのタップ領域は 44px 以上、3 列に並ぶ

## 使う設定の鍵
dopamine.yml: `cards.rarities`（内訳の段と順、枠の色、裏の「付け直すと」の段）、`read.complete_after_seconds`（空状態の文言）、`daily_goal.reset_hour`（束の日付）
personas.yml: なし
