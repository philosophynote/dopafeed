# Feeds（Unit 16a・第二の陣、#72。名前の変更は 16d、#99）

## 目的
購読の管理。フィードごとの件数・未読・最終取得・エラーを見せ、名前を変えられ、確認して削除できる。追加は AddFeed（#77）、手動更新は #22 完了後の別 Unit。

## 要素
1. 「購読 (4)」、リンク「フィードを追加」（→ AddFeed のシート）
2. フィード行 × N: タイトルと「名前を変更」、URL、「20件・未読 12」「最終取得 3分前」（DB: feeds + 集計）、取得失敗なら赤字「サーバーエラー (HTTP 503)」（DB: `feeds.last_fetched_at` は成否を問わない試行時刻、`feeds.last_error` が nil なら成功）
3. 注記「左にスワイプ、または削除ボタンで削除します。「名前を変更」で表示名を変えられます。取得に失敗したフィードは赤字でエラーが出ます」（固定）
4. タブバー（購読が選択）

## 遷移
- タブバー「購読」→ Feeds（full page）
- 左スワイプ / 削除ボタン → 影響を確認 → 削除して Feeds に戻る。確認キャンセルでは残る
- 「名前を変更」→ `GET /feeds/:id/edit` をその行のタイトルの Turbo Frame に読み、今の名前入りの入力欄と「保存」「やめる」に替わる → 「保存」で `PATCH /feeds/:id` → Turbo Stream で行ごと差し替える（削除の確認文も新しい名前に）。「やめる」で元の表示に戻る。JS が無ければ編集は単独のページで開き、保存で Feeds に戻る
- 名前は `feeds.title` をそのまま書き換える。登録時にフィードが名乗る名前が入り、以後は定期取得も移転（301/308）も書かないので、付けた名前は戻らない。Main の行・Reader・Jackpot も同じ列を読む
- AddFeed は 16b、引っ張って更新は #22 完了後

## 受け入れ条件（Given-When-Then）
- Given フィードが 4 件 When Feeds を開く Then 4 行、各行に件数・未読・最終取得
- Given 最終取得が 503 When Feeds を開く Then その行に赤字で「サーバーエラー (HTTP 503)」
- Given 削除 When 確認 Then Feed と記事・いいね・保存・読了が消え、別フィードと達成済み DailyGoal は残る（ADR 0014）。確認文に累計 XP・読了数・連続日数への影響を明記する
- Given 削除確認 When キャンセル Then フィードは残る
- Given 未取得 / 記事 0 件 / 購読 0 件 When 開く Then 「未取得」/「0件・未読 0」/「購読中のフィードはありません」
- Given 右・縦・短いスワイプ / 中断 When 離す Then 削除しない。390×844 で横スクロールがなく、タップ領域は 44px 以上
- Given フィード「Zenn のトレンド」 When 「名前を変更」→「Zenn」→ 保存 Then 行と Main の記事行のフィード名が「Zenn」になり、削除の確認文も「Zenn」。前後の空白は落とす
- Given 入力中 When 「やめる」 Then 名前は変わらず表示に戻る
- Given 空白だけ When 保存 Then 422 で入力欄の下に赤字「名前を入力してください」、名前は元のまま（空欄はブラウザが送らせない）
- Given 名前を変えたフィード When 定期取得（200 / 304 / 恒久移転） Then 名前は変わらない
- Given 入力欄 When 上で横に指を動かす Then 削除は始まらない
