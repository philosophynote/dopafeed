# Similar（Unit 未定・第二の陣。案: 14）

## 目的
個人最適化の第二軸。「あなた向け」（フィード重み + Claude）とは独立に、保存した記事との内容の類似で「読み返す候補」と「次に読む候補」を出す。

## 要素
1. ヘッダ: 「フィードに戻る」、「似ている記事」
2. 「いま読んでいる記事」: フィード名、見出し
3. 「保存した記事の中で似ているもの ・ 読み返す」: 保存記事 × 2（見出し、類似度「61%」、「共通: GPU、クラウド事業者、料金 ・ Hacker News ・ 保存 昨日」）。タップで元記事（外部 URL）
4. 「保存した記事に似ている未読 ・ 次に読む候補」: 未読 × 3（見出し、「既読の類似 84%」「保存に 58% 似ている」、理由、約 N 分）。タップ → Roulette
5. 注記「仕組み（コンテンツベースのアイテム間類似）…」（固定）

## 遷移
- Main の通常カードの「保存した『…』に 61% 似ている」→ Similar
- Saved の「保存した記事に似ている未読 3 件」→ Similar
- Similar → Roulette / 外部 URL / Main

## 受け入れ条件（Given-When-Then）
- Given 保存記事が 5 本 When 未読を開く Then 保存記事の重心とのコサイン類似で上位 3 本が出る
- Given 保存記事が 0 本 When Similar を開く Then 「保存するとここに出ます」の空状態
- Given 取り込み Job When 記事が増えた Then ベクトル化が同じ Job 内か後続 Job で走り、失敗しても記事の保存は成功する
