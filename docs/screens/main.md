# Main（Unit 5）

## 目的
無限供給と FOMO を担う入口。開くたびに「読むもの」と「今日の進み」が一画面に出て、記事の行を 1 タップすると画面を移らずにその下へ枠の帯・3 行要約・「記事に遷移」が広がる（#97、ADR 0019）。
未読の山ではなく「新着 + 発掘 1 本」として見せ、罪悪感ではなく期待で開かせる。

## 要素
上から順。出典: 固定 / DB / dopamine.yml の鍵。

1. ヘッダ: 「DopaFeed」ロゴ（固定）、「読む / 処理 / 流す」のラジオ（未読が 1 本以上のときだけ。#129、ADR 0023。#159 で「削除」から「処理」に改名。#194 で「流す」を足した）、フィード追加ボタン（「＋」のアイコン。→ AddFeed）、設定ボタン（→ Learning）
   - 「処理」の間は、行を左へ払うと削除、右へ払うと保存（#159、ADR 0030。右 = 保存・左 = 削除は読むモードと同じ向き。#171 で読むモードでも左へ払えば削除する）。引いた幅だけ、左へは右から丸型の背景とゴミ箱・「削除」が、右へは左からブックマーク・「保存」が伸び、閾値（`swipe.dismiss_threshold_ratio`）の手前は灰、越えたら赤（削除）・橙（保存）。削除ボタンは置かない。行のタップは読みにならない。切り替えた瞬間に広げていた欄は畳む。再読込・戻るでは「読む」で始まる
   - コンボ（処理モードの間だけ。ステータスの行に黒い帯で重ね、行の高さは変えない）: 「n COMBO」。削除・保存で払うたびに（離した時点で、応答を待たずに）1 増えて数字が弾み、効果音 `melody` がループするメロディ（16 音、8 音で一区切り）の n 音目を鳴らす。払う間合いがそのままリズムになる（音ゲー風、#129 26c）。処理モードでは閾値を越えた瞬間の `swipe` は鳴らさない（#159）。送れなかった削除・保存（待ちの上限を越えて後から成功が届いたら数え直す）とトーストの「元に戻す」で 1 減る（前の回の分を戻しても今の回は減らない）。モードの間は途切れない。ステータスの行はコンボの下で押せない（inert）。サーバーには残さず、ステータスの「n 連続」（読了の連続）とは別物（ADR 0023）
   - コンボの節目（#158、ADR 0023）: `delete_mode.combo_small_every`（5）の倍数で小、`delete_mode.combo_large_every`（10）の倍数で大。重なる数では大だけ。小は帯が橙に光り、帯の右端に「NICE!」が弾んで消え、`melody` に `combo_nice` を重ねる。大は帯の地が虹色に流れ（モードを抜けるまで虹のまま）、帯の中心から火花が散り「GREAT!!」が弾んで消え、`melody` に `combo_great` を重ねる。文字と光は帯の中、火花は帯の周りに散るだけで、一覧の位置は動かさず、払う指を止めない（火花は払う操作を妨げない）。節目の文字は次の数に変わると消える。回の中で届いた一番上の数を超えたときだけ出す（元に戻して届き直しても出し直さない）。待ちの上限を越えて後から届いた成功で数え直したときは出さない（押していない瞬間に鳴らさない）。「処理」に入り直すと帯は黒に戻り、節目は 0 から。動きを減らす設定では動かさず、文字と音と止まった虹だけ。鍵が無ければ出さない
   - リザルト（「処理」から「読む」か「流す」へ切り替えた瞬間、1 件以上処理していれば Main の上に重ねる dialog。#194 で「流す」を足した）: 「リザルト」、件数と「処理した」（カウントアップ。動きを減らす設定では最後の数だけ）、内訳「削除 a ・ 保存 b」（#159）、タイム（「処理」に切り替えてから戻すまで。1 分未満は「n 秒」、以上は「m 分 n 秒」）、1 件あたりの秒数（小数 1 桁）、効果音 `fanfare`、「閉じる」（背景を押しても閉じる。画面を移って戻ると閉じている）
   - 「流す」（無限スクロールモード。読み上げは「無限スクロール」。#194、ADR 0036）: このモードの間に一度画面に入った行が、下端まで画面の上へ流れ切ったら削除する。スクロールが止まったときにまとめて送り、トースト「n 件を流しました」の「元に戻す」でひとまとまりを戻す。流した行は抜かずにその場で薄くなり「流した ・ タップで戻す」が重なる。タップするとその 1 本だけが戻り、トーストは残る。入る前に上へ流れていた行・広げた行・読み終えた行・戻した行は流さない。払いとタップは読むモードと同じ。最後まで流し切れるよう一覧の下に一画面ぶんの余白が付き、全部流すと余白の上に「全部流した。」が貼りつく。再読込・戻るでは「読む」で始まり、流した行は出ない。カード・今日のゴール・ストリーク・コンボ・リザルトに数えず、音は鳴らさない
2. フィードの切り替え（#192、ADR 0035）: 「すべて n」と、未読のあるフィードを未読の多い順に「Zenn 12」「Qiita 3」…。1 段で、はみ出す分は横に流す。選んだものは黒地。押すと `GET /?feed=<id>` でそのフィードの未読だけを並べる（再読込でも、別の画面から戻っても残る。切り替え自体は履歴に積まない）。件数は払う・片付ける・元に戻すの応答で書き直し、0 になったフィードは薄くして開き直すまで残す。未読のあるフィードが 1 つだけで絞っていないときは出さない。段の分だけ、画像つきの行は 6 本目の見出しが隠れる（nao が受け入れた）
   - ~~セグメント「すべて / あなた向け」~~（あなた向けは未決 1。この段はフィードの切り替えに使った）
3. ステータスカード（白。#91 で 1 行に詰め、行ごと DailyGoal への入口にした。左から「🔥 N日連続」「ドット n / 5」「M 枚」（図鑑のカードの数。#106、ADR 0020）「n 連続」。語「今日のゴール」「図鑑」は読み上げにだけ残す）
   - 「N 日連続」炎アイコン（DB: ストリーク）
   - ~~「未読 N 件 ・ 読了 N」~~（#91 で外した。未読はタブバーのバッジ、読了累計は出さない）
   - ~~「Lv.N」と XP バー「238 / 400 XP」~~ → 「M 枚」（DB: `Reading.card_count` = 完読の数。XP とレベルは #106 で廃止。ADR 0020）
   - 「今日のゴール n / 5」とドット 5 個（DB: 今日の読了数、dopamine.yml `daily_goal.articles`）。見えるのはドットと「n / 5」だけ。タップ（行全体）→ DailyGoal
   - コンボバッジ「n 連続」（今日の連続完読が 2 本以上のときだけ。倍率は無い。#106、ADR 0020。「あと 2:14」は出さない。有効時間は未決 3）
4. 新着バナー（白ピル）「新着 12 件 ＋ 過去の神記事を 1 本発掘」（DB: 前回開いた後の新着数。発掘は未決 4）
5. 記事の一覧（新しい順。種類 3 つ。通常の行は白い 1 枚の中に細い線で区切って並べ、カードの枠・影・隙間は持たない。#91）
   - 掘り出し物カード: 枠がグラデーション。フィード名、はてブ数「128 users」（DB、未決 5）、相対時刻、ラベル「掘り出し物」（モックの「XP ×K」「完読で +M XP」は ADR 0020 で数値の報酬をやめたので出さない。未決 11: カードの属性か、出目か）、見出し、要約 2 行（DB: summary）、「約 N 分」（N は未決 6）、いいね / 保存 / コメント（→ Comments）、「読む」ボタン（→ Reader。モックの Roulette は ADR 0026 で撤去）
   - 今日限定カード: 赤枠。ラベル「今日限定 ・ 残り 4:12:08」（未決 7。モックの「消える前に読むと +30 XP」は出さない）、アイキャッチ画像（DB: 未決 8）、「読む」ボタン
   - 通常の行: 左に見出し（太字、最大 3 行）、その下にフィード名・相対時刻（1 行）。右に OGP 画像のサムネイル（DB: image_url。幅 112px・3:2・角丸。無ければ出さず見出しが全幅。#87、ADR 0016）。「保存した『…』に 61% 似ている」（→ Similar。第一の陣では出さない）。行には要約を出さない（タップした後に作るので読む前はほぼ空。行の下に広げた欄で読む。ADR 0015・0019）。「読む」「興味なし」の文字ボタンは置かない: 行全体が「読む」。左へ払うと削除、右へ払うと保存（#171、ADR 0032。#129 で読むモードの左の削除をやめ、#171 で戻した）。読むモードの削除はコンボ・リザルトに数えず、閾値を越えた瞬間に `swipe` を 1 回鳴らす
   - 広げた欄（行をタップすると行の真下に出る。一度に 1 行だけ。#97、ADR 0019）: 枠の帯（DB: readings.tier。段は `cards.rarities`。Reader と同じ `readings/_rarity_band`。判定が届くまで「判定中」で段のリールが回り続け、届くと段を 2 周して止まり「24 点 レア ・ 完読でレアカード」。一番下の段以外は色を変えて光る。レアは橙、S レアは紫、頂点の SS レアは金色で、金の光が帯を走り、欄の中にコインが降る。枠の決まった帯は回さない。#100、#134、ADR 0026）、「Claude の 3 行要約」（DB: summary。作成中・失敗・上限の文言は Reader と同じ）、橙の「記事に遷移」（元記事を別窓、iPhone のホーム画面アプリではシート）、開いた後だけ出る「読み終えた」、判定後の区切り（Reader と同じ。手に入れたカードは裏からめくれて出るが、金でも全画面の開封は出さない。ADR 0019。未完なら区切りの下に「読み終えた」を置き直し、同じ欄で読み直せる）。大きい OGP 画像は出さない
   - 区切りの見せ場（#100 22b）: Reader と同じ（reader.md 要素 4。カードの下の 6 軸のレーダーも同じ。#134）。金でも全画面は出さず、欄の中の見せ場（火花とファンファーレ）だけ。カードを手に入れた応答では、上の 1 行の「M 枚」が弾む。連続が `cards.fever_combo` に届いたら「n 連続」のバッジが虹色になる
   - 効果音（#100、ADR 0022。Learning のトグルで切れる）: 行のタップ、スワイプが閾値を越えた瞬間、広げた帯の判定が届いて一番下の段以外で止まったとき（レア・S レアは rare、SS レアは gold）、判定の区切り（完読はめくり、未完は煙）。どれも現れた瞬間に 1 回だけで、再読込や履歴で戻っても鳴り直さない
   - 一覧の下の「残り n 件を片付ける」（読むモード・処理モードとも。#189、ADR 0035。フィードで絞っていれば「Zenn の残り n 件を片付ける」で、絞った行だけ。#192）: 押すと、この表示で並べた未読をまとめて削除する。n は見えている行の数で、払うたびに減り、元に戻すと増える。見える行が 0 本なら出さない。確かめの dialog は挟まず、トースト「n 件を片付けました」の「元に戻す」で全部戻る。カード・今日のゴール・ストリーク・コンボ・リザルトに数えず、音は鳴らさない
6. タブバー: フィード（未読バッジ 48、aria-current）/ 保存 / 図鑑（モックの「レポート」の枠。#106、ADR 0020）/ 購読（固定。第一の陣ではフィード以外は無効。未決 9）

## 遷移
- Login → Main（認証後の after_authentication_url）
- Main の行のどこかをタップ → 行全体が「読む」の POST（`expand=1`）→ Reading を作り、要約と判定の Job を積み、Turbo Stream で行の下の欄を埋めて広げる（モーダルは出さない。#97、ADR 0019）。同じ行をもう一度タップすると送らずに畳む・開く。別の行を広げると前の行は畳む。JS が無ければ直接 Reader へ
- 広げた欄の「記事に遷移」→ 元記事が別窓（シート）で開き、Stimulus `sheet` が `POST /readings/:id/start` で開いた時刻を記録 → 閉じて戻る（Reader と同じ合図）か、開いた後に出る「読み終えた」を押す → `POST /readings/:id/advance?from=main` → Turbo Stream で「読み終えた」を区切り（「<希少度>カードを手に入れた！」・滞在と n 本連続・今日のゴール、goal 本目なら「宝箱を開く」。未完なら「カードにならなかった」。#106、ADR 0020）に替え、上の 1 行（`#status-card`）と未読数（タブバー・アイコンのバッジ）を書き直す。次の記事は開かず、行はその場に残る（Main を開き直すと完読した記事は出ない）。JS が無ければ Main へ redirect（#97、ADR 0019）
- Main → DailyGoal（ステータスの 1 行をタップ。達成前でも開く。5 本目の読了後は Reader の区切りの「宝箱を開く」から。Unit 7 #55）
- Main → Comments / Similar / ForYou / Learning / AddFeed / Saved / Weekly / Feeds（full page。第一の陣では無い）
- 第一の陣の導線: 設定ボタンは Learning の最小版（`/learning`。サインアウト + Install への導線だけ。Unit 5 で置いた）へ。フィード追加の「+」は出さない（5 フィードは seed と Unit 3 で入る。AddFeed は第二の陣）
- 第二の陣（#77）: 「フィードを追加」から AddFeed のシートを開く。閉じると Main に戻る
- Reader（Saved の行・JS 無しから開く）の「閉じる」で Main に戻ると、完読したカードは一覧から消え、ステータスカードが更新される（Reader が判定する。ADR 0010）
- 一覧の下の「残り n 件を片付ける」→ `POST /sweep`（並べた記事の id をすべて送り、サーバーが未読で絞り直す。行の送信と同じ列に並べる）→ Turbo Stream で消した行が消えて「n 件を片付けました」のトーストが出て、未読数が減る。トーストの「元に戻す」→ `DELETE /sweep`（消した記事の id だけ）で行が元の位置に戻る（#189、ADR 0035）
- 流すモードで行が画面の上へ流れ切る → スクロールが止まったときに `POST /sweep`（`flow=1`、流れた記事の id。行の送信と同じ列に並べる）→ Turbo Stream で「n 件を流しました」のトーストが出て、未読数が減る。行は差し替えない。トーストの「元に戻す」・薄い行のタップ → `DELETE /sweep`（タップは `keep_toast=1` で 1 本だけ）で行が元の見た目に戻る（#194、ADR 0036）
- 行を左へ払う（読むモード・処理モードとも。#171）→ `POST /articles/:id/dismissal`（行の送信の列に並べる。右へ払うと `POST /articles/:id/bookmark`。#159）→ Turbo Stream で行が消えて画面下（タブバーの上）に「元に戻す」のトーストが出て、未読数が減る（swipe.md、ADR 0012・0023・0032、#112、#129、#171）

## 受け入れ条件（Given-When-Then）
- Given 未読記事が 3 本ある When Main を開く Then 3 本が published_at の新しい順に並ぶ
- Given 記事に summary がある When 行を見る Then 要約は出ず、見出しとフィード名・相対時刻だけ出る（#91）
- Given 画像つきで見出しが 3 行に折り返す記事が並ぶ When Main を開く Then 1 行の高さは 120px 以下（一画面に並ぶ本数を減らさない。#91）
- Given 未読の行 When 見出し・時刻・画像のどこをタップ Then 画面を移らずに行の真下へ枠の帯・3 行要約・「記事に遷移」が広がり、Reading が作られる。モーダルは出ない（#97）
- Given 広げた行 When もう一度タップ Then 送らずに畳み、次のタップで送らずに開く（#97）
- Given 1 行を広げている When 別の行をタップ Then 前の行は畳まれ、広がるのは 1 行だけ（#97）
- Given 要約の無い記事 When 行を広げる Then 要約の Job が積まれて「要約を作成中…」が出て、Job が書き終えると再読込せずに要約が出る（ADR 0015・0019）
- Given 判定済みでレアの記事 When 行を広げる Then 帯が橙で光る。頂点の段でも全画面へは進まない（#97）
- Given 判定中の帯 When 判定が届く Then 帯のリールが段を 2 周し、`cards.reveal_duration_ms` で止まってから光る。止まった瞬間にレア・S レア・SS レアの音が鳴る。履歴で戻っても回り直さない（#100、#134）
- Given 頂点の段の判定が届いた When 帯が止まる Then 金の光が帯を走り、欄の中だけにコインが降る（画面は覆わない）（#100、#134）
- Given 動きを減らす設定 When 判定を待つ・判定が届く Then リールは回さずに段を出し、コインも出さない（#100）
- Given 広げた行 When 「記事に遷移」で開いて complete_after_seconds 以上たって戻る Then 欄に「<希少度>カードを手に入れた！」の区切りが出て、上の 1 行の本数と枚数が増え、未読数が 1 減る。画面は移らず、次の記事の Reading は作られない（#97、#106）
- Given 広げた行 When 開いてすぐ戻る Then 区切りは「カードにならなかった」で、今日の本数は変わらない（#97、#106）
- Given 頂点の段に決まった行 When 広げた欄で完読する Then 区切りに金の枠のカードがめくれて出るが、全画面の開封は出ない（Reader だけ。ADR 0019、#106）
- Given 未完の区切りが出た欄 When もう一度「記事に遷移」で開いて読んで戻る（または「読み終えた」を押す）Then 測り直して判定し、区切りは 1 つだけ（#97。Reader と違い、一覧の欄では未完の後も開き直す）
- Given 「記事に遷移」を押して合図が来ないまま別の行を広げた When その行の記事から戻る Then 畳んだ行は判定されない（#97）
- Given 広げた行 When 「記事に遷移」を押していない Then 「読み終えた」は出ていない（#97）
- Given 今日 goal − 1 本読んだ When 広げた欄で完読する Then 区切りに「宝箱を開く」（#97）
- Given 広げた行 When 見出しの上から右へ引く Then 行だけが動いて広げた欄は動かず、離すと行ごと消える（#97。左は削除。#129 → #159 → #171）
- Given 未読の行 When 「処理」に切り替えて左へ閾値の先まで引いて離す Then 削除ボタンは無く、行が消えてトーストが出て未読数が 1 減り、`dismissed_at` が入る。Reading は作られない（#129、#159）
- Given 処理モード When 右へ閾値の先まで引いて離す Then 行が消えて「1 件を保存しました」のトーストが出て、`bookmarked_at` が入り、コンボが 1 増える（#159）
- Given 処理モード When 左右とも閾値の手前で離す Then 行は戻り、何も送らず、コンボも増えない（#159）
- Given 処理モード When 続けて 3 本左へ払う Then 3 本とも消えてサーバーにも 3 件入り、トーストは最後の 1 枚だけ（#129、#159）
- Given 処理モード When 流れ出した行をもう一度引く Then 送信は 1 本（#159）
- Given 処理モード When 行を押す Then 広がらず、読みにならない（#129）
- Given 行を広げている When 「処理」に切り替える Then 欄は畳まれる（#129）
- Given 処理モード When 別の画面から戻る・再読込する Then 「読む」で始まる（#129）
