# データとジョブのレビュー

1. `AGENTS.md` と `SECURITY.md` を読み、対象の版と比較元を確認する。モデル、マイグレーション、ジョブ、サービスの差分から、呼び出し元と永続化・外部通信まで追う。必要な観点は [Model の確認項目](references/model.md) で引く。
2. `db/schema.rb` と関連テストを突き合わせる。SQLite の制約、トランザクション、既存データの移行を確認する。`FeedFetcher` と `ArticleRetention` に関わる変更では重複取り込みや削除後の記事の復活、保存・読了済みデータへの影響を確認する（ADR 0027）。
3. Solid Queue の再試行と同時実行では、更新、通知、要約・判定の呼び出し、日次予算が重複する条件を確認する。要約と判定はそれぞれ既存のサービスと Job の経路を追う（ADR 0024、0028）。再試行・欠損・恒久的な失敗で残るデータを確認する。
4. 関連する RSpec、既存のモック、クエリと制約を証拠にする。セキュリティに関わる確認と報告は `SECURITY.md` に従う。指摘、確認事項、検証結果を `AGENTS.md` に従って日本語で返す。
